# Project manager notes

The log the project manager appends to, the archive kelpie rolls it into, and the standing notes only kelpie writes. The agent is in pm.md, its board in pm-board.md.

- Tools `Read,Glob,Grep,Edit,Write`; writes only to the end of `pm-notes.md` via `kelpie confine --append`. Kelpie rolls that log past 32 KiB into `pm-archive.md` at a wake, and keeps what a later wake must remember in `pm-standing.md`, which only kelpie writes and asks every wake to mine the archive into until a `standing` answer lands. #327, #988, #1365
- `pm-standing.md` holds the rules that hold across work items, each carrying when it stops holding at the line's end: `(until #12)` or `(until 2026-10-05)`. Only the last `(until ...)` group closing a line is an end; one mid-line, one before the last group, or one that does not parse is plain text and the line stands. At wake kelpie rewrites the file without every line whose end has passed, before the wake reads it, and a tell heading whose only line went goes with it. Each line that goes is its own `standing ended:` line in `pm-notes.md` and is named to the PM once; nothing new goes in `dropped`. A ticket end the board cannot answer is read once a wake through `ports.tickets` in the wake's off-lock job (#1210, `runner-lock.md`): any close ends the line, `not planned` included, and a read that fails keeps the line and names it as unsettled once a wake, a wake that failed and handed what it carried back included. A date end holds through the named day in the clock the tell headings use. An end names a ticket, never a pull request: for a pull request the PM names the issue it was filed from, which kelpie closes when it merges. The state of one work item goes in `pm-notes.md`. #1366, `runner/pm/notes.rs`
- Kelpie appends one line to `pm-notes.md` for every wake it answered: the time, what it woke for, what it did, and the answer's `why`, each on one line, cut at 300 characters at the last word that fits, with text naming this machine withheld as on the board. An answer it gave, or one it owed, on a ruling left to it is recorded among what it did, since a wake for a ruling alone has no other action. A wake that failed or gave no readable answer appends nothing, and each tell it carried goes to the standing notes verbatim in the same step. The PM adds only what a later wake needs and that line does not say, and a resumed wake is not sent back to reread its notes. #989, `runner/pm/notes.rs`
