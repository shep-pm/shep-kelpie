# Agent allow list

Which agents a project may use. The agent settings are in agents.md, the agent file in agent-files.md.

- `agents.allow` (optional list of agent names, absent allows every agent with a file, `[]` refused at load saying to leave it out): the only agents the project may use, for a private project that keeps its code to the models its owner names. `find` in `crates/core/src/settings/agents/mod.rs` refuses a name the list leaves out, naming the setting that holds it and `agents.allow`, for each `agents.implementers` entry, `agents.pm`, `agents.representative`, `triage.agent`, `contributions.security_reviewer` and each listed or default reviewer (`agents.reviewers`, `contributions.reviewers`; a default one names `agents.reviewers` as the other fix). `Runner::implementer_files` returns only the implementer files it holds, so an `agent:` label names an allowed implementer or is skipped as `LabelError::NoAgent`, and labels are made only for them. Names are not checked against the agents folder, since files are reread each wake: a missing file is refused where the name is used. `fallback_after` and the default implementer need nothing, since every listed implementer passed the check. `upgrade` and `settings migrate` write no `allow`.
