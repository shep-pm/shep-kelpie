# Waits and spend

A model that is not there yet, a due turn held up, a step that keeps failing, what a role spends, and how an agent's usage is read. Agent files, harnesses and gateways are in agents.md.

- Local implementer (`usage: none`) can be default; without a gateway keep `active_items` 1. #381
- Turn awaiting its model marked `waiting` in memory; with `agents.fallback_after`, waiting first turn moves to next free implementer; later or pinned turns never (lose session). A turn's last output is read from the call's stdout file for pi (`crates/adapters/src/adapters/pi/activity.rs`: none until a model event, a `message_update`, `tool_execution_*`, `compaction_*`, `auto_retry_*` or an assistant `message_end` with content, so the opening lines pi writes at once do not count; a file past 1 MiB counts unread; a last line without its newline is not read) and Codex, not pi's session file, which moves once per message. goose is read the same way (`crates/adapters/src/adapters/goose/activity.rs`: a `message`, `notification` or `error` line counts, the banner and `complete` do not; a file past 1 MiB counts unread; a last line without its newline is not read), but coarser than pi's: goose streams no text, so a whole assistant message is one line, and a model generating a long answer or long reasoning shows no event until it ends. A slow model can read as silent, and `agents.fallback_after` is 10 minutes by default. #381, #768, #790, `runner/flight/waiting/`
- A new work item opens on the agent board's pick (agent-board.md), writing no `agent:` label. `next_free` picks a waiting first turn's fallback, and skips a gateway model whose `GET /paddock/status` shows every lease turn held and a waiter, other clients included; a missing turn limit or a failed read counts as free. #1283, #1335, `runner/flight/waiting/`, `crates/adapters/src/adapters/paddock/mod.rs`
- OpenAI gateways expose no lease-turn status and count as free. `docs/parity.toml`, `runner/flight/waiting/`
- Unreachable pi, goose or Codex host (or an overloaded Codex provider) retried 30s to 5 min for 30 min before parking. Codex's reading is `AgentError::Unreachable` from `parse_result`, with `unbounded_connection_retries` off so a down host ends the turn (#836); the leading-status rule is shared in `crates/adapters/src/adapters/unreachable/mod.rs`. #457, #776, `runner/turn/unreachable/`, `crates/adapters/src/adapters/codex/mod.rs`
- `usage` (`claude`, `codex`, `none`) must match harness; `none` never paced; a gateway queues its calls, a `url` model is unqueued. #129, #502
- Spend = tokens per role, dollars only where reported; unpriced calls counted (zero never reads as free). #129
- A due turn that does not start says why in `status` (`held_up`) and on the board line: no slot, push by someone else, pacer hold, token wait, drain, `attach`. Memory only; one log line once held 5 min. A CI wait with no check reported shows `checks: "none"` beside its `since`, memory only. #503, #1163, `runner/turn/held_up.rs`
- A work item's step that fails again and again shows `failing` (`since`, `failures`, `reason`) in `status`, from its second failure in a row; any other outcome clears it. Memory only. Retries keep the 15 s to 10 min backoff. #1162, `runner/looks/mod.rs`
