# Agent board

The estimate the agent board picks an implementer by: when each agent would finish a work item, and what it would cost. ADR 0018. The code is pure and in `crates/core/src/agent_board/`; the dog does not call it yet, so no pick runs on it.

- Typical time and cost (`History`, `typical.rs`): from the usage ledger's merged `finished` lines (metrics-work-items.md), the median `wall` of the first level that holds 5 items (`SAMPLES`): the agent's own items of the work item's kind, then every agent of its tier with that kind, then its tier with any kind. The cost is the median `cost_usd` of that level's priced lines, those with no `unpriced_calls` in either role, and unknown when none is. With no level, 1 hour (`DEFAULT_SECS`) and an unknown cost. An even count takes the mean of the middle two. A line's tier is its agent's tier as the caller reads it from the agent files, not the line's `tier`, which is what the item asked for; a line whose agent no file names counts toward no tier. A line or work item with no kind (a rework or an adopted item, or an issue with no `kind:` label) counts only toward the tier's any-kind level. Assumed chain: ADR 0018 names only the agent's kind and then its tier, so the tier's kind before its every kind, and the 1 hour default, are this file's reading.
- Typical turn (`History::turn_secs`): the same chain over each line's `wall` divided by its worker calls, since the line keeps no worker seconds, so a turn reads long by the review and CI time. A line with no worker calls gives no turn. With none, 1 hour.
- Wait (`wait`, `wait.rs`): a gateway model's `ModelLoad` (`crates/core/src/ports/leased.rs`) has `held + waiting + 1 - slots` turns ahead when positive, served `slots` at a time, so the wait is `ceil(ahead / slots)` typical turns. A model that lists no slots has no turn limit and waits 0. An unread load has no window: the agent is not picked, never read as free. A plan account waits until its pacer `Hold`'s `until`, and with no hold waits 0. An `Unreadable` hold waits until kelpie looks again, its `until` `RECHECK_SECS` on. An agent with neither waits 0.
- Pick (`pick`, `pick.rs`): of the candidates, keep those whose file takes the item's kind (a file with no `kinds` takes every kind; an item with no kind goes only to such a file), whose tier is at least the item's, that are not left out, that have a window, and only the pinned one when the item has a pin. Finish is wait plus typical time. Those finishing within the item's slack of the soonest (its pick's minutes, else 60, `DEFAULT_SLACK_MINUTES`) come first, cheapest first, an unknown cost last, then soonest; the rest follow soonest first, so a handoff can take the next. Empty when none fits.
