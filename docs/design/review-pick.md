# Review pick

How a pass chooses each round's reviewer. The pass it sits in is in review.md.

- Each round asks the agent board (`board_picks`) for a reviewer: the item's kind, tier and slack, no pin, as candidates every reviewer file `agents.allow` holds but `contributions.security_reviewer` that can run (`paths`, a down local, a bot's `rounds`), and the pass's reviewers left out, with every bot the project left out as one its repo cannot run within the last 7 days. It takes the first ranked one the pacer lets start (`Scope::Turn`) and, for a bot, whose window is open now; a held one or a bot with a closed window is skipped, not waited on, and a bot is passed over (`bots_skipped`, so a late review is still read). A board that cannot be reached leaves the round to ask again next poll, with no fallback. A reviewer counts toward `need` once its round ran, not a bot passed over or a reviewer that kept failing. The pass goes to CI at `need` reads or when the board ranks none left; every held one waits on the first hold. ADR 0018, #1539, #1541, `runner/review/lineup.rs`
- A board that ranks none of the candidates that could run, with nobody having read, marks the item `unreviewed` (a ruling, not CI and an auto merge): a tier no reviewer file fits or a file the board does not know yet cannot send a pull request through unread. A bot kelpie itself left out is none the board was asked to rank, so the reason names it as left out with when it comes back. After a read it only ends the pass. `runner/review/lineup.rs`
- The start's, the reread's and `doctor`'s checks (CodeRabbit on a repo that is not public, a local reviewer that does not answer, a review bot that has never reviewed on the repo, a reviewer on a gateway kelpie cannot route) hold only the reviewers `agents.allow` names, and a reread runs them when the naming changed or a named reviewer's file did. A candidate it named no is passed over at its round, by the repo's visibility or as down, and one on a gateway kelpie cannot route is no candidate at all. `runner/reviewers_check.rs`, `settings/reviewers/mod.rs`, `doctor/project.rs`. #1544
