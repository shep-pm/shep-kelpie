# Guide

The operator reference for shep-kelpie, one page for each topic. [Getting started](../../README.md#getting-started) comes first.

- [Writing issues](issues.md): the `issue` skill, `shep kelpie issue check` and the `agent:` label
- [Local tickets](tickets.md): a project's tickets as files in kelpie's home, and `shep kelpie ticket`
- [The board and the project manager](board.md): what decides whether and when an issue starts, the briefing and the project manager
- [Contributions](contributions.md): pull requests from other people, and their security review
- [Triage](triage.md): finding the issues other people opened that nobody has touched, and getting your own ready for an agent
- [Building](building.md): the worker, skills, repo plugins, `repo_setup`, the repo's own files, MCP servers, the code graph and retros
- [The review](review.md): the reviewers, review bots, comments from people and local reviewers
- [CI and the merge](ci-and-merge.md): red runs, the merge gate and what `auto` does
- [Agents](agents.md): agent files, gateways, pi and Codex
- [Attaching to a worker](attach.md): steering a work item's worker by hand
- [Rulings](rulings.md): the seven kinds, how to answer them, and answers from GitHub and ntfy
- [The GitHub App](github-app.md): registering kelpie's App, what a worker's token can do, and the tools and login token
- [Upgrading](upgrading.md): moving the dog and the runners onto a new build
- [What shep does for it](shep.md): supervision, lambs, triggers, settings and logs
- [Commands](commands.md): `status`, `usage`, `watch`, `doctor` and the rest, and pausing and finishing
- [Metrics](metrics.md): the series on shep's metrics endpoint, the alerts and the dashboard
- [Leases and end-to-end tests](leases-and-e2e.md): the `cargo-test` lease and running e2e tests on another host
- [Settings](settings.md): every key, what `add` writes, and shep-kelpie's own settings
- [shep-kelpie's home](home-and-logs.md): where it keeps its files, and its logs
